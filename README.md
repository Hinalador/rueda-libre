# Rueda Libre

Sitio estático para conocer la flota, consultar tarifas y solicitar bicicletas en Medellín.

## Versión 2.0.0

La versión 2.0 incorpora un tema compartido de Bootstrap, variables de marca, clases propias `rl-*` y Bootstrap Icons en Inicio, Tarifas y Reservas.

También incluye un carrusel fotográfico en la portada y validación visual con un modal de resumen en el formulario de reservas. El formulario es solo de frontend y todavía no envía datos a un servidor.

## Tecnologías

- HTML y CSS
- Bootstrap 5.3.3
- Bootstrap Icons 1.11.3
- JavaScript para la validación y el resumen de la reserva

## Ejecución local

Abre `index.html` con una extensión de servidor local, como Live Server. Las hojas de estilo e iconos de Bootstrap se cargan desde jsDelivr, por lo que requieren conexión a internet.
